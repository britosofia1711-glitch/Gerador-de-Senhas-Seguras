# 🔐 Gerador e Analista de Senhas Seguras

Aplicação desktop desenvolvida em Python para geração automatizada de senhas personalizáveis, análise em tempo real do nível de força da senha e persistência de dados em arquivo local.

## Tecnologias Utilizadas

* **Linguagem:** Python
* **Interface Gráfica:** Tkinter
* **Manipulação de Arquivos:** I/O (`.txt`)
* **Controle de Versão:** Git e GitHub

## Funcionalidades

* **Geração Personalizada:** Permite escolher o tamanho da senha e incluir ou remover símbolos.
* **Análise de Força:** Classificação dinâmica da senha em **FRACA**, **MÉDIA** ou **FORTE** com base na complexidade.
* **Validação de Entradas:** Tratamento de erros com janelas de alerta para impedir entradas inválidas.
* **Armazenamento Local:** Vinculação do nome do serviço (ex: Instagram, E-mail) e gravação automática em arquivo `minhas_senhas.txt`.
